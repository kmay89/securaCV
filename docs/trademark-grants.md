# Trademark grants — the public registry

Every grant of the SecuraCV primary marks (logo, mascot, prominent use of the
name) is recorded here, added by pull request, per the
[trademark & branding policy](../TRADEMARK.md) §4. If a use of the primary
marks isn't in this table, it isn't granted.

The **"Works with SecuraCV" badge needs no entry here** — it is free for any
use that meets the policy's §2 rules, no registration required.

| Grant | Holder | Marks | Scope | Granted | Expires | Status |
|-------|--------|-------|-------|---------|---------|--------|
| _none yet — the registry is open_ | | | | | | |

**To request a grant:** open a GitHub issue titled
`Trademark grant request: <who> — <what>` describing who you are, which mark,
and how it will be used. Approved requests are merged into this table as
`TG-001`, `TG-002`, … with a two-year term. Renewals re-use the ID with a new
`Granted` date.
