How this works & why you can trust it

Nothing leaves this page. The bundle is read and checked entirely in your browser using the Web Crypto API. There are no network requests — open your browser's Network tab and watch: it stays empty. You can save this file and run it air-gapped.

It re-derives the proof, it doesn't take the device's word for it. For the bundle to pass, every one of these must hold:

  • The ruleset manifest matches the canonical specification (rules travel with the data).
  • The whole-bundle fingerprint recomputes to the value embedded in the bundle.
  • Each event is hash-chained to the one before it — no insertions, deletions, or edits.
  • Every entry carries a valid Ed25519 signature from the device's key.
  • Checkpoints, break-glass approvals, and the export receipt all verify and bind together.

This viewer implements the same algorithm as the project's Rust verifier, and the two are pinned to identical test fixtures in CI. Post-quantum (ML-DSA) signatures, when present, are reported as not checked here rather than assumed valid.
